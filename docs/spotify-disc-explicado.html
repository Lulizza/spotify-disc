Um widget do Plasma 6 é uma pasta com um metadata.json e arquivos QML. QML é a linguagem de interface do Qt, e lembra CSS com JavaScript. O Plasma lê essa pasta e desenha o widget. Os números na árvore ao lado seguem a ordem desta página.

01

metadata.json

A identidade do widget.
  • "KPackageStructure": "Plasma/Applet": diz que o pacote é um widget (applet).
  • "Id": "local.spotifydisc": o nome único. É o que você usa em plasmawindowed local.spotifydisc, e o widget é instalado em ~/.local/share/plasma/plasmoids/local.spotifydisc/.
  • Name, Description, Icon, Category: o que aparece em "Adicionar widgets".
  • "X-Plasma-API-Minimum-Version": "6.0": exige Plasma 6.

O Plasma procura o arquivo principal por convenção, em contents/ui/main.qml.

Achar o Spotify (MPRIS)

MPRIS é o padrão do Linux para controlar players de música pelo DBus. Spotify, VLC, Firefox e outros se anunciam assim. O Plasma traz um módulo pronto para isso, o mesmo que o controlador de mídia da bandeja do sistema usa.

Mpris.Mpris2Model { id: mpris2Model }    // lista de todos os players abertos
Instantiator { model: mpris2Model; delegate: QtObject { ... } }
  • O Mpris2Model é uma lista com um item por player aberto.
  • O Instantiator cria um pequeno objeto para cada player, guardando o container (o player em si), o desktopEntry (ex.: "spotify"), a identity (ex.: "Spotify") e o isMultiplexer. O multiplexer é um player "virtual" que representa o player ativo, por isso é ignorado.
  • pickPlayer() percorre esses objetos e escolhe o que tem "spotify" no nome. Se não houver nenhum e anyPlayer estiver ligado, usa o player ativo do sistema.
  • Ela roda sempre que um player abre, fecha ou muda de nome. Qt.callLater junta várias chamadas seguidas numa só.

O player escolhido fica em root.player, e dele saem propriedades derivadas:

readonly property bool playing: player.playbackStatus === Mpris.PlaybackStatus.Playing
readonly property string track:  player.track
readonly property string artist: player.artist
readonly property string artUrl: player.artUrl         // URL da capa
readonly property real lengthSec: player.length / 1e6  // MPRIS usa microssegundos

Isso é binding do QML: quando player.track muda, root.track muda junto, e tudo que depende dele (o texto na tela, a busca da letra) se atualiza sozinho.

A posição da música

O MPRIS não avisa quando a música avança, só quando você pula de trecho. Por isso o widget faz duas coisas:

  1. A cada 2 s chama player.updatePosition() e pergunta a posição real ao Spotify.
  2. Entre essas perguntas, estima a posição sozinho. Um Timer de 250 ms atualiza tick (a hora atual), e a barra anda suave.
posição = última posição real + (agora − momento dessa leitura) × velocidade

posStamp guarda o momento da última leitura real. Ele é renovado quando a posição muda ou quando você dá play/pause, para a barra não pular depois de uma pausa. seekTo(segundos) muda player.position: é assim que clicar na barra ou numa linha da letra pula o trecho.

O botão Curtir

QML não faz login OAuth com facilidade, então o trabalho fica com o spotify_like.py. O QML só roda o script e lê a resposta:

P5Support.DataSource { engine: "executable" ... }
  • exec.run("python3 '<caminho>' status", callback) roda o comando.
  • Quando ele termina, chega onNewData com o stdout. O widget lê a última linha como JSON (ex.: {"liked": true}) e chama o callback.
  • likeState guarda o estado do botão: unknown, liked, notliked, noauth, busy ou error.
  • Quando a música muda, um Timer de 800 ms espera os dados do Spotify se estabilizarem e então pergunta status.
  • Clicar no ♥ roda toggle. Se a resposta for noauth, o clique abre a configuração.

Representação compacta e completa

  • compactRepresentation: quando o widget está no painel. Mostra a capa redonda em miniatura. Clique esquerdo abre o widget, botão do meio dá play/pause.
  • fullRepresentation: o widget completo. Na área de trabalho (formFactor === Planar) aparece direto.

Plasmoid.backgroundHints: NoBackground desliga o fundo padrão do Plasma, porque o widget desenha o seu próprio.

Layout da representação completa

Uma coluna (ColumnLayout), de cima para baixo:

  1. Fundo: Rectangle com cantos arredondados, degradê azul, borda e sombra (MultiEffect).
  2. Quadrado do disco, que ocupa o espaço que sobrar, com três coisas sobrepostas: o Disc (fica transparente e encolhe para 85% quando a letra abre), a LyricsView (aparece com fade quando showLyrics é verdadeiro) e o RoundButton no canto superior direito, que alterna showLyrics.
  3. Título em negrito e artista em subtle. Os dois cortam com "…" se forem longos.
  4. Barra de progresso feita à mão: trilho, preenchimento azul com largura posição / duração, uma bolinha que só aparece no hover, e um MouseArea. Enquanto você arrasta, a barra mostra dragFrac; ao soltar, chama seekTo.
  5. Tempos: posição à esquerda, duração à direita (fmt formata como m:ss).
  6. Botões: ⏮ player.Previous(), ⏯ player.PlayPause() (maior e preenchido), ⏭ player.Next() e o ♥. O coração é um Shape com caminho SVG: contorno quando não curtido, preenchido de azul quando curtido. Um espaçador invisível do tamanho do ♥ fica antes dos botões para centralizar o play.
05

contents/ui/Disc.qml

O desenho do disco, em camadas.

Usa as proporções de um CD/DVD real de 120 mm: o furo tem cerca de 12,5% do raio, e o hub de plástico transparente vai até 36%.

A função-chave é ring(raioExterno, raioInterno). Ela gera um caminho SVG com dois círculos. Com fillRule: OddEvenFill, só a área entre eles é pintada e o miolo fica vazado: um anel com furo. Cada círculo é feito com 4 arcos de 90°, porque arcos de 180° em SVG são ambíguos.

  1. Sombra: um anel preto invisível passado a um MultiEffect com shadowEnabled. Por ser anel, não escurece o furo.
  2. Rotor, a parte que gira (NumberAnimation on rotation, 360° em 9 s). paused: !disc.spinning faz o disco parar no ângulo em que estava. Dentro dele:
    • Capa: uma Image escondida que serve de fonte a um MultiEffect com máscara. A máscara é o anel branco, então a capa só aparece no formato do disco. Sem capa, usa um degradê.
    • Hub: anel com degradê radial branco translúcido, mais três círculos finos, como as marcas em relevo de um disco de verdade.
  3. Reflexo iridescente, fora do rotor, então não gira. A luz que bate num CD fica parada enquanto ele gira. É um anel com ConicalGradient (degradê em leque) com faixas de ciano, rosa e amarelo em dois lados opostos.
  4. Borda externa: um contorno branco fino.
06

contents/ui/LyricsView.qml

A letra, sincronizada quando possível.

A letra vem do lrclib.net, um banco gratuito e sem chave de API. Muitas letras lá vêm sincronizadas no formato LRC:

[00:12.34] primeira linha
[00:15.80] segunda linha

Busca: fetchLyrics

  1. Tenta a busca exata, /api/get?track_name=…&artist_name=…&album_name=…&duration=….
  2. Se não achar (404), tenta a aproximada, /api/search?…, e prefere um resultado com letra sincronizada.
  3. Guarda o resultado num cache em memória (_cache).
  4. _key (artista + música) descarta respostas antigas se a música trocar no meio da busca.
  5. Só busca quando a aba de letra está aberta (active).

Interpretação: parseLrc

Uma expressão regular pega cada [mm:ss.xx] e transforma em segundos. Uma linha pode ter vários tempos, como um refrão repetido. Linhas vazias viram "♪". No fim, ordena por tempo.

Linha atual: currentLine

É a última linha cujo tempo é menor ou igual à posição da música, com 0,25 s de antecipação para não parecer atrasada.

Exibição: ListView

  • highlightRangeMode com preferredHighlightBegin a 38% da altura mantém a linha atual nessa faixa e rola a lista sozinho.
  • A linha atual fica maior, azul e opaca. As que já passaram ficam mais apagadas.
  • Se você rolar com o mouse, a rolagem automática pausa por 3 s.
  • Clicar numa linha emite seekRequested(tempo), e o main.qml pula a música para lá.
  • Letra sem sincronia aparece como texto rolável comum.
  • Mensagens de estado: "Buscando letra…", "Letra não encontrada", "♪ Instrumental ♪" e erro de rede.
07

contents/ui/RoundButton.qml

Botão redondo reutilizável, usado em ⏮ ⏯ ⏭ e no botão de letra.
  • Recebe size, iconName, fg (cor do ícone), bgColor (fundo), filled (fundo sempre visível ou só no hover) e tooltip.
  • O ícone é um Kirigami.Icon com isMask: true, que pinta o ícone do Breeze com qualquer cor.
  • Anima a escala ao clicar e no hover, e fica com 40% de opacidade quando desabilitado (ex.: sem música).
08

contents/ui/configGeneral.qml

A tela de configurações.
  • property alias cfg_clientId: clientField.text e os outros cfg_*: o Plasma liga cada cfg_NOME à opção NOME do main.xml. Não há código para salvar; OK/Aplicar fazem isso.
  • Duas caixas de seleção: girar o disco e usar outro player.
  • Um texto com o passo a passo para criar o app no Spotify, com link clicável.
  • O campo do Client ID. Conectar só fica ativo com exatamente 32 caracteres hexadecimais (validId). Isso também protege, porque o valor vai para uma linha de comando.
  • Conectar roda python3 spotify_like.py auth <clientId> e mostra o resultado. Desconectar roda logout, que apaga o token salvo.
09

contents/code/spotify_like.py

Login no Spotify e curtidas. Só biblioteca padrão do Python; sempre imprime uma linha JSON, que é o que o QML lê.

auth <client_id>: login OAuth com PKCE

PKCE é o jeito seguro de fazer login em apps que não conseguem guardar uma senha secreta, como um widget.

  1. Gera um verifier aleatório e o challenge (o hash SHA-256 dele).
  2. Sobe um mini servidor HTTP em 127.0.0.1:8898.
  3. Abre o navegador (xdg-open) no login do Spotify, pedindo user-library-read e user-library-modify (ler e alterar as Músicas Curtidas).
  4. Você aceita e o Spotify redireciona para http://127.0.0.1:8898/callback?code=…. O servidor confere o state (proteção contra falsificação) e mostra "Conectado!".
  5. Troca o código + verifier por um access token (cerca de 1 h) e um refresh token (longa duração).
  6. Salva em ~/.config/spotifydisc/token.json com permissão 600. Escreve num arquivo temporário e renomeia, para nunca deixar o arquivo pela metade.
  7. Sem resposta em 5 minutos, desiste.

access_token()

Se o token vale por mais de 60 s, usa ele. Senão, pega um novo com o refresh token, sem novo login. Se o Spotify recusar, responde {"error": "noauth"}.

status e toggle

  1. Descobre a música atual pelo DBus (gdbus call … Metadata). O ID vem num campo como /com/spotify/track/4uLU6hMCjMI75M1A2tKUQC. O QML não passa o ID de propósito, para nada vindo de fora entrar na linha de comando.
  2. is_liked pergunta à Web API se a faixa está curtida: tenta GET /me/library/contains?uris=spotify:track:ID e, se falhar, o antigo GET /me/tracks/contains?ids=ID.
  3. set_liked usa PUT para curtir e DELETE para descurtir, com o mesmo esquema de endpoint novo e reserva no antigo.
  4. toggle consulta, inverte e responde {"liked": true/false}.

Erros possíveis: noauth (não conectado), notrack (Spotify fechado, anúncio ou arquivo local) e HTTP <código>.

install.sh

Instala ou atualiza o widget.
kpackagetool6 -t Plasma/Applet -s local.spotifydisc   # já está instalado?
  → sim: kpackagetool6 -u package   # atualiza
  → não: kpackagetool6 -i package   # instala

O kpackagetool6 copia package/ para ~/.local/share/plasma/plasmoids/local.spotifydisc/. Como o Plasma guarda o QML em memória, depois de atualizar é preciso reiniciar o plasmashell (ou reabrir o plasmawindowed).
